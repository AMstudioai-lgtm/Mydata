# Mydata

Application Android de bases de données locales et de tableaux personnalisés.
Vos données sont stockées sur votre appareil et restent accessibles hors connexion.

## Téléchargement

Dernière version : https://github.com/AMstudioai-lgtm/Mydata/releases/latest

Téléchargez le fichier `.apk`, puis autorisez l'installation d'applications
provenant de sources inconnues pour votre navigateur ou gestionnaire de fichiers.

## Mise à jour entre deux versions

Pour mettre à jour, désinstallez d'abord la version actuelle, puis installez le
nouveau APK.

À noter : désinstaller l'application supprime les données stockées sur l'appareil.
Pensez à exporter ou sauvegarder vos informations importantes avant la mise à jour.
